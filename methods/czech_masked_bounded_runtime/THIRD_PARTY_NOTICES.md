The inherited transformations normalize integer-ID Czech FORM rows to NFKD/lowercase ASCII letters, remove boundaries, train smoothed wordless quadgrams on train data, select bounded development text, apply seeded bijective substitutions and replace unknown runs/singletons with sentinel 26. This package changes none of those retained data. It adds external runtime staging, a fresh fixed-budget P05 replay and separately labelled fabricated interface probes. Unknown gaps are not word boundaries or certified one-unit ciphertext symbols.
