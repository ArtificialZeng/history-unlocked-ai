# History Unlocked AI

AI-assisted historical cipher research by Zijian Zeng, UCSI University.

[简体中文](README.zh-CN.md) · [Čeština](README.cs.md) · [日本語](README.ja.md)

The public release is being rebuilt with reproducible code, necessary research data, methods and case documentation. Media submissions and private correspondence are kept separately and are not part of this repository.

The public [HC615 record](https://api.hcportal.eu/api/cryptograms/615) marks the item Solved and credits Zijian Zeng. Results for other cipher problems are being verified by other experts.

Star the project to follow verified updates. Fork the code to reproduce and extend the work.
