### 一条命令复核

```sh
git clone https://github.com/ArtificialZeng/history-unlocked-ai.git
cd history-unlocked-ai
python3 -B scripts/verify_portfolio.py --replay
```

需要 Python 3.10 或更新版本。离线复核只使用标准库，校验科学输入的 SHA-256，执行 **8 个可运行案例、9 条验证命令**，包括回加密和适用的篡改检查。验证过程无需调用 AI、联网或登录；Private 仓库的克隆需要访问权限。

### 最新更新 · 2026 年 10 月 14 日

**让历史文字重见天日，也让每一步经得起复核。** 11 个研究条目继续保留 HC615 的官方确认，以及 HC1679 经独立审计的部分读解：276 个选定位置、2,633 项检查、15 处明确标出的未解释片段。可运行案例都有复现命令和科学输入哈希。

**最新实验：得分领先，还要经得起全文检验。** HC1527 完成了一次固定缺损正文实验与 99 份匹配打乱对照，保存全部 **1,800 次重启的数值记录**。实际输入得分高于所有打乱对照，条件性排序 p 值为 0.01。另一独立算术审计通过 **89,640 项检查**，但对四份逐字输出的盲审 AI 辅助审阅，没有确认完整连贯的消息。这条方法路线的继续研究可行性评分降至 79/100，已停止。公开数值记录与离线检查器可复核得分比较和停止依据；它们不重新执行目标破解，也不证明历史释读正确。[查看完整实验记录](research/trials/hc1527_fixed_model_v1/README.md)。

**新增：每次搜索，都留下可复核的轨迹。** 固定预算运行程序校验代码、模型和输入的哈希，检查固定种子，保留全部 18 次重启，并限制运行时间与进程数量。未知符号继续保留，不用猜出的文字补齐。重新编译后的 P05 复现得到相同结果，也保留了那一个字符的错误。固定的 99 次打乱对照已在上述 HC1527 实验中完成。[查看固定预算运行工具](methods/czech_masked_bounded_runtime/README.md)。

**新增：空格消失、符号缺损，仍能恢复可读文字。** 在另一次无词界捷克语测试中，6 个 400–600 字母的合成样本包含被遮蔽的单个符号和长度未知的片段。求解器**完整恢复 5/6 个样本的已知位置，2,612/2,613 个已知字符正确（99.96%）**，仅按频率排序的基线为 575/2,613。另一独立 AI 辅助流程通过 **3,156 项复核**。一个字符的失败原样保留；被遮蔽的 387 个原始字符不计为已恢复。公开包包含源码、固定遮蔽规则与种子、全部 162 次重启输出、离线验证器和重新求解的命令。这是合成样本上的方法成果，历史研究条目仍为 11 个。[复现缺损符号测试](methods/czech_wordless_masked_masc/README.md)。

### 为什么值得关注

历史档案的障碍往往同时涉及符号转录、语言判断、编码规则和来源核查。AI 能协助组织这些工作、编写专用程序；可复现证据让任何有兴趣的人检查读出了什么、使用了哪些假设、还有什么不能确定。

HC615 在目录中约定年为 1952 年，属于捷克斯洛伐克密码分析课程材料。读出的捷克语内容涉及工人赴俄斯特拉发参加一年期劳动队。同一套固定映射解释全部观察符号，让历史文字的恢复有了逐字符可检查的依据。

### 证据怎样组成

- 保留准确条目编号、公开来源链接和转录记录。
- 明确标出不确定笔画、覆盖旧层和编辑恢复。
- 固定密钥、模型与候选，再复核来源证书。
- 从候选明文回加密，对照每个观察单元。
- 按案例执行对照与篡改检查，并单独记录外部核验结论。
