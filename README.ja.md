# History Unlocked AI

## 隠された言葉。公開コード。検証できる成果。

**AI が冷戦期の暗号文を読み解く。その証拠を、あなたもコードで確認できます。**

**UCSI University の Zijian Zeng** が率いる歴史暗号研究プロジェクトです。チェコ語の単一換字式暗号、PORTAX、回転グリル、条件付きの鍵転用による読解を対象に、再現用コード、必要な研究データ、方法を公開します。

[English](README.md) · [中文](README.zh-CN.md) · [Čeština](README.cs.md) · [日本語](README.ja.md)

**HC Portal #615 は公式目録で Solved と記載され、Zijian Zeng の解読として紹介されています。** 他の暗号問題の読解結果は、他の専門家が検証中です。結論は順次反映します。

[公式記録](https://crypto.hcportal.eu/dashboard/cryptograms/615) · [公開状態の記録](docs/HC615_PUBLIC_CATALOGUE_STATUS.json) · [HC615 の読解](cases/hc615/docs/SOLUTION.md)

### 再現方法

```sh
git clone https://github.com/ArtificialZeng/history-unlocked-ai.git
cd history-unlocked-ai
python3 -B scripts/verify_portfolio.py --replay
```

Python 3.10 以上が必要です。標準ライブラリだけでオフライン検証を実行し、SHA-256 と 8 案件の 9 検証コマンドを確認します。AI 呼び出しや通信は不要です。非公開リポジトリのクローンにはアクセス権が必要です。

### 最新更新 · 2026年10月14日

**歴史の言葉を取り戻し、その証拠を誰でも検証できる形に。** 11件の研究項目には HC615 の公式確認と、独立監査済みの HC1679 の部分読解を収録しています。HC1679 は選択した276箇所を2,633項目で検証し、15区間の未解決部分を明示しています。実行可能な案件には再現コマンドと科学データのハッシュを保持しています。

**新機能：空白のないチェコ語を一文字ずつ復元。** 移植可能な換字式暗号ソルバーは、200・400・600文字の合成メッセージ6件をすべて完全に復元しました。**2,400/2,400文字が一致**し、頻度順だけのベースラインは596/2,400でした。別のAI支援監査で156項目と完全な再暗号化を確認し、新たにコンパイルした再実行も凍結出力と一致しました。ソースコード、固定シード、対照データ、検証コマンドを公開しています。欠損のない現代チェコ語での試験であり、歴史的な手書き文字、欠字、他の暗号方式には別の検証が必要です。[再現可能なソルバー](methods/czech_wordless_masc/README.md)。

### 歴史の言葉を、検証できる形に

HC615 は、1952 年頃のチェコスロヴァキアの暗号分析講習資料として登録されています。チェコ語の本文は、労働者をオストラヴァの一年間の労働隊へ送り出す内容です。一つの固定写像で 220 記号、32 区間、8 行を説明できます。アクセントや一部の文境界は編集上の復元であり、元の符号列から一意には決まりません。

AI は転記、分析、作業の整理、専用プログラムの作成を支援します。再暗号化と出典証明により、凍結した転記から何が言えるかを確認できます。未収録の原画像の再判読や、世界初の証明を意味するものではありません。
