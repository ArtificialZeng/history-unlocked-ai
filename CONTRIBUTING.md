# Help unlock more history

Star the project to follow new results. Fork it to reproduce the certificates,
review the source observations, or propose a better documented interpretation.

Useful contributions include independent code replay, Czech and German language
review, checking the exact original catalogue item for an earlier reading, and
identifying original answer sheets. Cite the catalogue ID and distinguish an
observed source reading from an editorial restoration or a hypothesis.

Before opening a pull request, run:

```sh
python3 -B scripts/verify_portfolio.py --replay
```

Keep frozen scientific inputs unchanged. Submit a new version with an explicit
change record for proposed corrections. Do not add correspondence, conversation
logs, submission drafts, document bundles or third-party source images. Code,
necessary data, method documentation and brief project promotion belong here.
Preserve the applicable case licences and attribution.
