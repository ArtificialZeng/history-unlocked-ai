# History Unlocked AI

Historické šifry a reprodukovatelný výzkum s podporou AI. Zijian Zeng, UCSI University.

[English](README.md) · [简体中文](README.zh-CN.md) · [日本語](README.ja.md)

Veřejná verze se připravuje a obsahuje pouze kód, nezbytná výzkumná data a popis metod. Texty pro média a soukromá korespondence zůstávají mimo repozitář.

[Oficiální záznam HC615](https://api.hcportal.eu/api/cryptograms/615) uvádí Solved a jméno Zijian Zeng. Výsledky dalších šifrových úloh nyní ověřují další odborníci.

Sledujte projekt pomocí Star a využijte Fork k reprodukci a rozšíření kódu.
